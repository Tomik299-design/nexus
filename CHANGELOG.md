# NexusChat Changelog

## v3.2 | 2026-03-29
+ Login system — ID + přezdívka = účet přes prohlížeče
+ Zapamatovat účet — zůstaneš přihlášený po refreshi
+ Sync serverů přes server — servery se obnoví po přihlášení
+ Historie zpráv uložena na disk — noví uživatelé vidí staré zprávy
+ Automatický changelog z CHANGELOG.md souboru
* Zprávy se posílaly do špatného chatu po DM
* Voice room správně zobrazuje kdo je ve voice kanálu
* Odpojení z voice nyní ihned uklidí UI
* Bany a offline členové přetrvají po restartu
^ Výkon optimalizován pro hraní na pozadí

## v3.1 | 2026-03-27
+ Voice volání přes WebSocket relay — funguje všude bez WebRTC
+ Noise Gate — filtruje dýchání a hluk pozadí
+ Hlasitost mikrofonu a výstupu v Audio nastavení
+ Test mikrofonu s živým měřičem úrovně
+ Přepínač jazyka CS / EN
+ DM seznam v sidebaru s odznaky nepřečtených
+ Připnutí a smazání zpráv v DM
+ @mention picker — napiš @ pro označení člena
+ Oprávnění kanálů — omez kdo může psát
+ Drag & drop členů mezi voice kanály
^ Výkon — rendering se přeskočí při hraní na pozadí
